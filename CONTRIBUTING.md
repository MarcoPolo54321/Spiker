# Участие в разработке

1. Создайте ветку от основной ветки и опишите цель изменений.
2. Используйте Python 3.11 x64 на Windows для проверки UI и упаковки.
3. Перед pull request выполните:

   ```powershell
   python -m unittest discover -s tests -v
   python -m compileall -q scripts tests
   ```

4. Не добавляйте записи, пользовательские настройки, API-ключи, журналы или веса моделей.
5. Изменения упаковки проверяйте через `build_windows.ps1`. GUI и нативный whisper.cpp нужно дополнительно проверить на Windows.
6. Укажите проверенные сценарии, окружение и известные ограничения в описании pull request.

# Сообщение об уязвимости

Не публикуйте API-ключи, личные записи, результаты транскрибации или приватные логи в открытых issues. Для чувствительных проблем обратитесь к сопровождающему репозитория через доступный приватный канал GitHub, если он настроен. В отчёте укажите версию СПИКЕРА, версию Windows, шаги воспроизведения и минимальные технические сведения без пользовательского аудио/текста.

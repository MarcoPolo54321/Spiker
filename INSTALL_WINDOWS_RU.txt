СПИКЕР 3.1.3 — установка в Windows 10/11 x64

УСТАНОВКА (рекомендуется)
1. Скачайте оба файла одного профиля и версии: `Spiker-Setup-3.1.3.exe` и
   `Spiker-Models-3.1.3.zip` для полной версии либо файлы с суффиксом `-Basic`.
2. Поместите их в одну папку. Архив моделей остаётся ZIP-файлом; установщик сам
   разложит содержащиеся в нём файлы в папку приложения.
3. Запустите установщик. Он устанавливает программу только для вашей учётной
   записи; права администратора не нужны.
4. Оставьте предложенную папку и нажмите «Установить». Ярлык на рабочем столе
   можно включить на следующем шаге.
5. Откройте СПИКЕР из меню «Пуск» или с рабочего стола.

Полная версия содержит Whisper Medium и Small, авторазделение голосов,
потоковую диктовку и русские модели озвучки (Ирина и Руслан). Компактная версия
содержит Whisper Small, авторазделение, потоковую диктовку и те же голоса.
В «Документы\Spiker» находятся расшифровки, настройки и результаты; перенос папки
программы не переносит их. Python для работы установленных сборок не требуется.
Для встроенного GigaChat модель весом около 6,5 ГБ скачивается отдельно;
инструкция находится в `docs/MODELS.md`.

ПОРТАТИВНАЯ ВЕРСИЯ
1. Скачайте `Spiker-Portable-3.1.3.zip` либо `Spiker-Portable-3.1.3-Basic.zip` и
   одноимённый по версии `Spiker-Models-3.1.3.zip` (для Basic — `-Basic`).
2. Распакуйте Portable ZIP в отдельную папку. Поместите ZIP моделей рядом с
   созданной папкой `Spiker`; не распаковывайте его вручную.
3. Запустите `Spiker.exe`. При первом старте программа сама разложит модели из
   соседнего архива.
3. Настройки, очередь и расшифровки находятся в `Документы\Spiker`; папка программы остаётся переносимой без личных записей.

ДАННЫЕ И УДАЛЕНИЕ
Все версии хранят настройки и результаты в `Документы\Spiker`;
они сохраняются при обновлении. Удалите программу через «Параметры Windows →
Приложения → Установленные приложения». Пользовательские данные удаляются
отдельно, только если они больше не нужны.

АВТОМАТИЧЕСКОЕ РАЗДЕЛЕНИЕ ПО ГОЛОСАМ
В полной версии выберите готовую запись в очереди и нажмите «Авто-спикеры».
Программа сначала распознаёт слова и затем соотносит интервалы голоса с
текстом. Если число участников известно, задайте его в поле «Спикеров» рядом
с кнопкой: значение 2 заставит модель строить ровно два голосовых профиля.
Значение сохраняется; «Авто» вернёт выбор числа модели. Переименуйте профили
на странице участников.

ПОДДЕРЖКА
Если приложение не запускается, перезагрузите компьютер и повторите запуск.
В полную версию встроены локальные модели разделения голосов. Подробности и сборка из исходников: `README.md` и
`docs/BUILD_WINDOWS.md`.

СПИКЕР 3.1.4 Refresh — установка на Windows 10/11 x64

ИЗ GITHUB
1. Скачайте Spiker-Setup-3.1.4-Windows.exe и Spiker-Models-3.1.4-Windows.zip из одного релиза. Положите их рядом. Не открывайте и не распаковывайте ZIP.
2. Запустите EXE и укажите папку установки. Для распаковки пакета нужен запас свободного места: рекомендуем не менее 3 ГБ. При обновлении выберите папку существующей установки.
3. Откройте СПИКЕР из меню «Пуск». В базовом комплекте доступны файловое распознавание (Whisper Small) и диктовка (T-one, Vosk). Как установить дополнительные голоса, модели участников и локальный ИИ, описано в README:
https://github.com/MarcoPolo54321/Spiker#дополнительные-модели

ЛОКАЛЬНЫЙ АВТОНОМНЫЙ КОМПЛЕКТ
Если у вас Spiker-Setup-3.1.4-Refresh.exe, используйте одноимённые архивы с суффиксом Refresh. При наличии всех пяти ZIP (базовый, Medium, Large-v3, Local-AI и Dictation) Setup установит их автоматически. Для полного комплекта оставьте не менее 18 ГБ. Архивы Windows, Refresh и Basic не взаимозаменяемы.

После установки добавьте короткую тестовую запись в «Загрузить файл», выберите модель и нажмите «Запустить очередь». Для диктовки можно оставить микрофон Windows по умолчанию. Раздел «Обучение» содержит видеопримеры.

ПОРТАТИВНАЯ ВЕРСИЯ
Папку с Spiker.exe и models можно скопировать на другой ПК. Это также переносит установленные модели разделения по голосам. Расшифровки и настройки хранятся отдельно в «Документы\Spiker».

Для старого Spiker-Setup-3.1.4-Basic.exe нужен архив Spiker-Models-3.1.4-Basic.zip.

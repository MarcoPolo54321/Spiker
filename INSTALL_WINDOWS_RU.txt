СПИКЕР 3.1.5 — установка на Windows 10/11 x64

Скачайте два файла:
• Spiker-Setup-3.1.5.exe из релиза v3.1.5;
• Spiker-Models-3.1.4-Windows.zip из релиза v3.1.4-refresh.

Оставьте ZIP без изменений. Положите оба файла рядом и запустите EXE. Установщик проверит архив и установит базовые модели распознавания и диктовки. Для обновления выберите существующую папку СПИКЕР: установленная библиотека моделей сохранится.

Чтобы подключить Ollama на другом ПК, установите её адрес в «ИИ-обработка». На сервере Ollama разрешите подключения из сети и входящий порт 11434 в брандмауэре Windows. Инструкция: docs/LOCAL_AI_LAN_RU.md или https://github.com/MarcoPolo54321/Spiker/blob/v3.1.5/docs/LOCAL_AI_LAN_RU.md.

Дополнительные модели можно установить позже по руководству на странице GitHub. Передача текста на удалённый сервер требует подтверждения.

Папку с приложением и моделями можно скопировать на другой компьютер. История остаётся отдельно в «Документы\Spiker».

# СПИКЕР 3.0.5 — релизная упаковка для Windows и GitHub

## Основные изменения

- Основной пользовательский путь — один `Spiker-Setup-3.0.5.exe`, создаваемый Windows-сборкой.
- Установщик/portable-комплект включает Python-приложение, библиотеки Qt, аудиокомпоненты и FFmpeg через PyInstaller.
- По умолчанию в сборку скачивается мультиязычная Whisper Small модель с закреплённой ревизии; SHA-256 проверяется до упаковки. Пользователь может выполнять транскрибацию без предварительной загрузки модели.
- README обновлён на русском языке с баннером и настоящими скриншотами приложения; добавлен английский README.
- Добавлен `GITHUB_ABOUT.md` с коротким описанием репозитория, topics и инструкцией для social preview.
- Документация уточняет границу offline: диктовка/транскрибация Whisper работают локально сразу после установки; Ollama и языковая модель для ИИ-обработки по-прежнему требуют отдельной предварительной установки/загрузки.
- Обновлены инструкция сборки, публикации и версия проекта до 3.0.5.

## Важно

Этот архив — репозиторий и сценарии сборки, не готовый Windows EXE. `Setup.exe` создаётся Windows GitHub Actions или скриптом `build_windows.ps1` на Windows. Перед стабильным релизом требуется ручная проверка на чистой Windows 10/11 x64.

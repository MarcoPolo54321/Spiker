# СПИКЕР 3.0.2 — примечания к обновлению

## Изменения

- Главные карточки «Диктовать», «Загрузить файл» и «ИИ-обработка» получили развёрнутые, краткие описания, подходящие для первого запуска; текст адаптируется за счёт переноса строк.
- Код обработки аудио переименован из `scripts/model/` в `scripts/transcription/`, чтобы визуально отделить Python-модули от файлов моделей.
- Установлен единый каталог весов `models/whisper/` и `models/vosk/`.
- При старте выполняется безопасная миграция известного старого расположения Vosk: `model/vosk-model-small-ru-0.22` → `models/vosk/vosk-model-small-ru-0.22`. Если перенос не удался, сохраняется совместимость со старым путём. Другие файлы в старом `model/` не удаляются.
- Добавлена ручная очистка старого кода `scripts/model/` для обновления поверх существующего проекта.

## Почему не объединяем содержимое без проверки

`models/` — каталог данных моделей (большие `.bin`-файлы Whisper и директории Vosk). Ранее `scripts/model/` — это Python-код, который подготавливает аудио и вызывает распознавание. Это разные типы данных: перенос кода в каталог весов приведёт к смешению программы и файлов нейросетей. В этой версии код находится в `scripts/transcription/`, а веса — в `models/`.

## Установка патча

1. Закройте СПИКЕР и сделайте резервную копию проекта.
2. Распакуйте ZIP-патч в корень проекта с заменой файлов.
3. Запустите `Launch_Spiker.bat`.
4. После успешного запуска выполните `Cleanup_Legacy_Model_Code.bat`, если в вашей установке осталась старая папка `scripts/model/`. Скрипт проверяет наличие нового кода перед удалением только устаревшей папки Python-модулей.

Большие модели, виртуальное окружение и пользовательские данные в ZIP не включены.

## Проверки

- Синтаксис всех Python-файлов.
- 16 unit-тестов проекта.
- Архивы ZIP: целостность и наличие обязательных файлов.
- Тест миграции старого каталога Vosk на временной файловой структуре.

Qt GUI на Windows и реальный движок распознавания необходимо проверить в пользовательской среде: в среде сборки PySide6 не установлен.

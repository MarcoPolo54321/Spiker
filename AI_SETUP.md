# ИИ-обработка в СПИКЕР 3.0

## Локальный режим без интернета

1. Установите Ollama для Windows, пока интернет доступен.
2. Откройте терминал и загрузите одну модель командой ниже. Либо запустите `Prepare_Local_AI.bat` — скрипт явно загрузит одну рекомендуемую модель, только если вы сами его запустите. Для целевой конфигурации 16 ГБ RAM и 8–12 ГБ VRAM начинайте с компактной модели; например:

   ```bat
   ollama pull qwen3.5:4b
   ```

   Более крупный вариант `qwen3.5:9b` можно проверить позднее, наблюдая за использованием VRAM и RAM. Фактический расход памяти зависит от квантования, контекста и runtime. Не нужно загружать модель повторно, если она уже отображается в `ollama list`.

   В список выбора также добавлена `qwen3.8:27b`. При необходимости установите её вручную:

   ```bat
   ollama pull qwen3.8:27b
   ```

   **Важно:** тег занимает примерно 18 ГБ на диске. При 16 ГБ RAM и видеокарте с 8–12 ГБ VRAM для запуска может не хватить памяти или модель будет работать медленно. Она оставлена как дополнительный выбор, а не модель по умолчанию. Не загружайте её, пока не убедитесь, что на диске достаточно места.

3. Запустите Ollama и проверьте, что модель установлена:

   ```bat
   ollama list
   ```

4. Запустите СПИКЕР и откройте третий блок **«ИИ-обработка»** на главном экране. Выберите **«Локальный ИИ · Ollama (офлайн)»**, адрес `http://127.0.0.1:11434/v1` и установленную модель.
5. Нажмите **«Проверить подключение / обновить модели»**. После успешной проверки можно отключить интернет: запросы будут идти на локальный сервер, пока он запущен и модель доступна.

СПИКЕР намеренно не загружает модели автоматически. Модельный файл не входит в ZIP, поскольку он большой и управляется отдельно от исходного кода.

## Обработка готовой расшифровки

- В очереди выберите завершённую задачу и нажмите **«Обработать с ИИ»** либо откройте третий блок **«ИИ-обработка»** на главном экране.
- Можно также просто вставить расшифровку в исходное поле или открыть TXT.
- Выберите действие и нажмите **«Обработать с ИИ»**.
- Результат отображается отдельно от оригинала и автоматически сохраняется в `results/ai/`.
- Для экспорта нажмите **«Экспорт результата…»**. Доступны Markdown, TXT и JSON.
- Для вопросно-ответного режима выберите «Ответить на вопросы по записи» и впишите вопрос в поле инструкции.

## Внешний API

Выберите «Внешний API · OpenAI-совместимый», укажите базовый адрес и имя модели. Введите API-ключ и сохраните настройки. Если `keyring` доступен, ключ сохраняется через системное хранилище учётных данных; в противном случае СПИКЕР не сохраняет его в открытом виде. Перед запуском появится подтверждение, что расшифровка будет отправлена наружу.

## Приватность и производительность

- Локальный режим не отправляет текст внешнему поставщику API; он обращается к локальному адресу Ollama.
- API-режим отправляет текст внешнему сервису — используйте его только для материалов, которые можно передавать выбранному поставщику.
- Для длинных записей СПИКЕР делит текст на фрагменты и собирает итоговый результат. Сверяйте имена, числа, сроки, решения и цитаты с исходной расшифровкой.
- При 16 ГБ ОЗУ и одновременной работе Whisper/LLM возможна конкуренция за память. Начните с небольшого локального варианта и не запускайте одновременно несколько тяжёлых моделей.
- Текущий Whisper backend остаётся CPU-only. Ollama может использовать GPU для языковой модели при совместимом драйвере и настроенном runtime; это не означает автоматическое ускорение Whisper.

## Устранение неполадок

- **Подключение не установлено:** убедитесь, что Ollama запущена, затем попробуйте `ollama list`.
- **Модель не найдена:** проверьте точный тег из `ollama list`; никаких скрытых автоматических загрузок нет.
- **Недостаточно памяти:** попробуйте меньшую модель, сократите текст или завершите транскрибацию перед ИИ-обработкой.
- **API не авторизуется:** проверьте API-ключ, базовый URL, модель и квоты поставщика.


## Размещение моделей в 3.0.2

Веса моделей хранятся в корневой папке `models/` (Whisper — `models/whisper/`, Vosk — `models/vosk/`). Код подготовки аудио и распознавания находится в `scripts/transcription/`. Это разные сущности и не должны помещаться в один каталог.

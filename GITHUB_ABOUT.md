## How to set it on GitHub

1. Open the repository page.
2. In the right-side **About** area, click the gear icon / **Edit repository details**.
3. Paste the Description above and add the suggested topics.
4. To set the social preview, open **Settings → General → Social preview → Edit** and upload `assets/readme-banner.jpg`.

This file prepares the exact copy and image; it does not update a GitHub repository remotely by itself.

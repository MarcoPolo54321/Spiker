# Правила для Codex и других помощников

Перед работой прочитай `CLAUDE.md`, `docs/CHANGE_MANAGEMENT.md` и `docs/progress.md`. Для затрагиваемого компонента прочитай карту из `docs/architecture.md`, принятые решения из `docs/decisions.md` и применимые инструкции из `docs/`.

`CLAUDE.md` — основной проектный стандарт; этот файл указывает на него, чтобы правила одинаково применялись в Codex и Claude Code. Не копируй сюда вторую версию правил: поддерживай ссылки актуальными.

Для любого изменения следуй процедуре `docs/workflow.md`. Не считай установленную папку, пользовательский профиль или каталог собранной программы исходным Git checkout. Перед изменениями проверь корень Git, текущую ветку и незакоммиченные правки. Пользовательские данные и веса моделей не меняй и не публикуй.

# СПИКЕР — голос в текст. Просто.

**Говорите, записывайте, расшифровывайте — остальное СПИКЕР поможет сделать проще.**

Настольное приложение для Windows: диктовка, расшифровка аудио и видео, плеер и ИИ-обработка готовых текстов.

[Скачать для Windows](#установка) · [Скриншоты](#скриншоты) · [Конфиденциальность](docs/PRIVACY.md) · Сообщить об ошибке — раздел Issues репозитория

</div>

СПИКЕР объединяет несколько задач в одном приложении: быстро записать идею, расшифровать длинную запись, прослушать нужный фрагмент и превратить текст в конспект, краткое содержание или протокол встречи.

**Меньше рутины — больше времени на то, что действительно важно.**

## Возможности

### 🎙️ Диктовка

Преобразуйте речь с микрофона в текст. Результат можно проверить, отредактировать и сохранить в файл. Подходит для заметок, идей, черновиков и повседневной работы.

### 🎬 Расшифровка аудио и видео

Преобразуйте речь из медиафайлов в текст. Добавляйте несколько файлов в очередь, обрабатывайте их последовательно, приостанавливайте задачу и продолжайте позже.

### 🎧 Работа с аудио

Встроенный проигрыватель позволяет прослушивать запись, перемещаться по звуковой дорожке и находить нужные фрагменты — удобно для проверки длинных расшифровок.

### ✨ ИИ-обработка текста

Создавайте краткое содержание и конспекты, структурируйте информацию, извлекайте задачи и улучшайте оформление расшифровок. Можно выбрать локальную языковую модель или подключить поддерживаемый внешний API.

### 🧠 Гибкая работа с моделями

Для распознавания речи используется Whisper; установщик Windows включает мультиязычную модель Whisper Small. Для потоковой диктовки можно настроить Vosk. Для обработки текста поддерживается подключение к локальным языковым моделям через Ollama.

### 🔒 Контроль над данными

Встроенная транскрибация выполняется локально. При использовании локальной языковой модели текст остаётся на устройстве, если Ollama и модель уже установлены и приложение настроено на локальный режим. Внешний API передаёт текст выбранному провайдеру; перед отправкой проверьте настройки и конфиденциальность исходных данных.

## Установка

### Для пользователей Windows

1. Откройте раздел **Releases** этого репозитория.
2. Скачайте **`Spiker-Setup-<версия>.exe`** — это основной установщик. Исходный ZIP и portable ZIP большинству пользователей не нужны.
3. Запустите установщик и следуйте подсказкам. Python, Qt и необходимые библиотеки приложения отдельно устанавливать не нужно.
4. После установки СПИКЕР готов к локальной транскрибации: установщик включает модель Whisper Small. Интернет для самого распознавания после установки не требуется.

> Если на странице Releases пока нет `Spiker-Setup-*.exe`, значит Windows-сборка ещё не опубликована. Она создаётся GitHub Actions после отправки версии-тега; см. [инструкцию публикации](docs/PUBLISHING.md).

### Локальная ИИ-обработка текста

Для ИИ-обработки готовых текстов через локальную языковую модель требуется [Ollama для Windows](https://ollama.com/download) и выбранная модель, например:

```powershell
ollama pull qwen3.5:4b
```

Чтобы пользоваться локальным ИИ без интернета, установите Ollama и скачайте модель заранее, пока сеть доступна. Языковые модели велики, поэтому они не включены в основной установщик. Внешний API доступен как дополнительный вариант и требует интернета.

Модель `qwen3.8:27b` доступна для выбора в приложении, но занимает около 18 ГБ на диске и может быть непрактична при 16 ГБ ОЗУ и 8–12 ГБ видеопамяти. Подбирайте размер модели под характеристики устройства.

## Для кого предназначен СПИКЕР

- **Работа:** расшифровка встреч, интервью, звонков и обсуждений.
- **Учёба:** конспекты лекций, записи занятий и структурирование материала.
- **Творчество:** голосовые заметки, фиксация идей и подготовка черновиков.
- **Повседневные задачи:** диктовка и быстрое преобразование речи в текст.

## Технологии

- **Python** — основа приложения.
- **Whisper / whisper.cpp** — распознавание речи.
- **Vosk** — необязательный движок потоковой диктовки.
- **Ollama** — подключение локальных языковых моделей.
- **PySide6 / Qt** — графический интерфейс.
- **Windows 10/11 x64** — целевая платформа.

## Разработка и сборка

Подробности для разработчиков находятся в [документации по сборке Windows](docs/BUILD_WINDOWS.md) и [публикации релизов](docs/PUBLISHING.md).

Для локальной сборки нужен Python 3.11 x64. Команда создаёт портативную папку, ZIP и, при установленном Inno Setup 6, `Setup.exe`:

```powershell
.\build_windows.ps1 -Installer
```

Установщик собирается на Windows runner и включает библиотеки приложения, FFmpeg и модель Whisper Small. Ollama и веса языковых моделей остаются отдельными компонентами.

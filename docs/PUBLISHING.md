# Публикация СПИКЕР на GitHub

## 1. Загрузить исходники

1. Создайте пустой репозиторий GitHub, например `Spiker`.
2. Распакуйте репозиторий так, чтобы `.github`, `.gitignore`, `README.md`, `VERSION` и `Spiker.spec` находились в корне.
3. В `GITHUB_ABOUT.md` найдите короткое описание и topics для блока **About**. В настройках репозитория их нужно вставить вручную, если репозиторий не подключён к API управления GitHub.
4. Загрузите исходники и отправьте их в ветку `main`. Перед `git add .` убедитесь, что личные записи, API-ключи и файлы моделей не попали в git.

```powershell
git init
git add .
git commit -m "Prepare Spiker 3.0.5 release"
git branch -M main
git remote add origin https://github.com/OWNER/Spiker.git
git push -u origin main
```

Замените `OWNER` и адрес `origin` на свой репозиторий.

## 2. Создать релизный Setup.exe

После загрузки исходников откройте **Actions → Windows build and release → Run workflow**. Ручной запуск создаёт артефакты для тестирования. Скачайте `Spiker-Setup-3.0.5.exe` из артефакта и проверьте его на отдельной/чистой Windows-машине.

Основной публичный релиз запускается тегом версии. Для `VERSION` со значением `3.0.5`:

```powershell
git tag v3.0.5
git push origin v3.0.5
```

Workflow должен собрать и прикрепить к GitHub Release:

- `Spiker-Setup-3.0.5.exe` — единственный файл, который рекомендуется большинству пользователей;
- `Spiker-Portable-3.0.5.zip` — переносная сборка для опытных пользователей;
- `SHA256SUMS.txt` — контрольные суммы.

Setup включает библиотеки приложения и Whisper Small, так что транскрибация работает без интернета после скачивания установщика. Ollama и большие языковые модели остаются отдельным компонентом. Не называйте релиз полностью автономным по ИИ, пока Ollama и выбранная языковая модель не поставляются в отдельном/offline AI пакете.

## 3. Включить красивую карточку репозитория

В **About → Edit repository details** вставьте описание из `GITHUB_ABOUT.md` и темы (topics). В **Settings → General → Social preview** загрузите `assets/readme-banner.jpg`. README уже содержит баннер и настоящие скриншоты, поэтому страница репозитория выглядит информативно сразу при открытии.

## 4. Проверка перед стабильным релизом

Не публикуйте первую собранную версию как стабильную без ручного теста на чистой Windows 10/11 x64. Выполните пункты из [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md), включая запуск без интернета и транскрибацию реального файла.

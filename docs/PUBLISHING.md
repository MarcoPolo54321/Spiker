# Публикация Windows

Для сборки из исходников см. [BUILD_WINDOWS.md](BUILD_WINDOWS.md). Обычные теги версий запускают сборку GitHub Actions. Тег `v3.1.4-refresh` выпущен вручную после проверки на Windows: это исключение из автоматической публикации, чтобы CI не заменял проверенные файлы.

На публичном релизе этот установщик называется `Spiker-Setup-3.1.4-Windows.exe`. Парный ZIP `Spiker-Models-3.1.4-Windows.zip` содержит только локальные модели распознавания. Для автономного комплекта с дополнительными моделями существует отдельный профиль `-Refresh`. Эти архивы нельзя смешивать: каждый установщик проверяет SHA-256 своего комплекта.

Для ручной публикации проверьте состав Git, установите сборку в чистую папку, пройдите основные сценарии, приложите EXE, совместимый ZIP и `SHA256SUMS.txt`. Не коммитьте пользовательские записи, настройки, ключи, журналы, тяжёлые модели и виртуальные окружения. Перед распространением дополнительных весов проверьте их лицензию и приложите требуемую атрибуцию. Ссылки на необязательные модели приведены в [README](../README.md#дополнительные-модели).

Стандартная автоматическая сборка по-прежнему поддерживает профиль Basic: например, `Spiker-Setup-3.1.4-Basic.exe` и `Spiker-Portable-3.1.4-Basic.zip` относятся к предыдущему релизу, а не к паре файлов Windows Refresh.

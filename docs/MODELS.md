# Модели СПИКЕР

## Whisper — распознавание аудио и видео

Публичный Windows-установщик содержит мультиязычную модель `ggml-small.bin` (~488 МБ). После установки приложение может распознавать речь локально без загрузки модели и без интернет-соединения.

Для более высокой точности или других компромиссов скорости/качества можно выбрать собственную совместимую модель `ggml-*.bin` в настройках. Типичные расположения:

```text
models/whisper/ggml-small.bin
models/whisper/ggml-medium.bin
```

Whisper Medium и другие дополнительные модели в базовый установщик не включаются: их можно добавить отдельно. Установка/обновление программы не должна требовать удаления моделей, добавленных пользователем.

Сведения об источнике, фиксированной версии и SHA-256 встроенной модели: [MODEL_SOURCE.md](../models/whisper/MODEL_SOURCE.md).

## Vosk — потоковая диктовка

Необязательная модель Vosk используется для получения промежуточных гипотез во время диктовки. Для её работы нужна полная папка модели с подкаталогами, например:

```text
models/vosk/vosk-model-small-ru-0.22/
```

Модель Vosk не включена в базовый установщик.

## Языковая модель — ИИ-обработка расшифровки

Для локальной обработки готового текста установите [Ollama для Windows](https://ollama.com/download) и предварительно загрузите совместимую модель, например:

```powershell
ollama pull qwen3.5:4b
```

После загрузки Ollama и языковой модели анализ может выполняться без интернета. Сама Ollama и веса языковых моделей в базовый установщик не включены из-за объёма и самостоятельного жизненного цикла моделей. Для компьютера с 16 ГБ RAM и 8–12 ГБ VRAM обычно разумнее начать с модели меньшего размера.

`qwen3.8:27b` доступна как вариант для выбора, однако занимает около 18 ГБ на диске и может требовать больше памяти, чем доступно в системе. Не скачивайте крупную модель без проверки свободного места и характеристик компьютера.

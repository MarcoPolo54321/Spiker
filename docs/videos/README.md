# Видеопримеры СПИКЕР

Короткие ролики работают без интернета. Нажмите кнопку «Видео» на карточке, чтобы открыть полноэкранный плеер СПИКЕРА. Вернуться к инструкции можно кнопкой «К инструкции» или клавишей Esc. В кадрах — интерфейс СПИКЕР и вымышленные примеры. Вместо звуковой дорожки используются подписи.

| Файл | Что показывает |
|---|---|
| `start.mp4` | Главное меню и переход в обучение |
| `dictation.mp4` | Системный микрофон Windows и результат диктовки |
| `queue.mp4` | Добавление файла, запуск очереди и экспорт |
| `speakers.mp4` | Имена участников, число голосов и точечная правка |
| `models.mp4` | Выбор модели распознавания для файла и диктовки |
| `speech.mp4` | Выбор голосов, озвучка и сохранение MP3/WAV |
| `ai.mp4` | Режим «Беседа с кандидатом», проверка отчёта и экспорт |

Сборка Windows включает всю папку `docs`. Для портативной копии держите `docs/videos` рядом с остальными файлами СПИКЕР.

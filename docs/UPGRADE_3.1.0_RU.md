# Обновление СПИКЕР 3.1.0

## Распознавание и говорящие

В файловой очереди включён faster-whisper Medium с отметками слов; после него идёт офлайн-модуль sherpa-onnx. Он выделяет речевые интервалы, сравнивает голосовые embeddings и группирует повторы в участника. Время слова используется для привязки каждой реплики; ранее точность зависела от Community-1, которой на компьютере не было. Установлены открытые сегментационная сеть pyannote 3.0 и WeSpeaker ResNet34. Пользователь может переименовать «Спикер 1» и «Спикер 2» в панели участников.

Проверено на публичном демонстрационном английском разговоре (2 из 2) и синтетическом русскоязычном чередовании двух женского/мужского Piper-голосов (метки `1,0,1,0`). Это подтверждает механику голосового сходства, но не заменяет полевую проверку на реальном разговоре с шумом/перебиваниями. Реальное устройство и пользовательские записи не использовались.

## Озвучка и локальный ИИ

Для озвучки скачиваются русские VITS Piper «Ирина» medium и «Руслан» medium (русская речь, 22.05 кГц). У Ирины в карточке upstream указан `License: Unknown`; проверьте условия распространения перед публикацией её весов. У Руслана карточка указывает CC BY-NC-SA 4.0: модель нельзя включать в коммерческую поставку без отдельного разрешения. Поэтому веса хранятся в локальном наборе моделей, а готовый ZIP/EXE не следует считать разрешённым публичным распространением без проверки лицензии.

GigaChat3.1-10B-A1.8B q4_K_M (~6.47 GB) распространяется как MIT по карточке модели. llama.cpp CPU запускается дочерним процессом на 127.0.0.1 с одноразовым ключом и выключается при выходе. Пробный запрос вернул две задачи с авторами. На 16 GB RAM модель заметно использует память; на целевом ПК тест занял 16.7 с с запуском сервера.

## Закрытие и приватность

Сеансовые черновики приложения и очередь сохраняются в `Документы/Spiker`. Старые `data`, `results`, `logs` из установленной и переносной папок копируются по одному отсутствующему файлу; существующие файлы назначения не заменяются. Рабочее состояние закрытия сохраняется перед отменой потоков. После 3 секунд неперерываемое нативное распознавание завершается вместе с процессом, чтобы пользователь мог закрыть окно; черновик и чекпоинт очереди уже записаны.

Тексты закрытой диктовки, редактора ИИ и озвучки восстанавливаются при повторном открытии соответствующей страницы.

## Android

`android/` содержит Kotlin-проект на той же синей теме и использует sherpa-onnx Android AAR 1.13.8. В комплекте общая потоковая модель T-one, сегментация голосов и два русских голоса синтеза. Пути и API использованы из официального Android API sherpa-onnx. Этот черновой APK не эквивалентен Windows по file/video queue, CTranslate2 Whisper Medium и GigaChat: их отдельный нативный runtime/размеры требуют Android-адаптации и теста телефона. APK должен собираться debug build после установки JDK 17 и Android SDK API 35.

## Контрольная запись

Контрольные синтетические аудио и результаты лежат в игнорируемой Git папке `validation_samples/`. Они не отправляются в публичный репозиторий. `models/download-manifest.json` записывает SHA-256 исходных загрузок.

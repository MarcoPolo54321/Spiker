# Подключение к локальной ИИ-модели по сети

1. На компьютере с моделью включите приём запросов из локальной сети. Ollama по умолчанию слушает только свой компьютер: задайте для службы Ollama переменную окружения `OLLAMA_HOST=0.0.0.0:11434` и перезапустите службу. Для LM Studio или llama.cpp включите доступ по локальной сети в настройках сервера.
2. Разрешите входящее TCP-соединение к порту модели в брандмауэре Windows только из частной сети. Для Ollama это обычно порт `11434`; LM Studio и llama.cpp показывают порт API в настройках.
3. На компьютере с СПИКЕРОМ откройте «ИИ-обработка». Выберите «Локальный ИИ · Ollama» или «Локальный сервер · LM Studio / llama.cpp». Укажите адрес сервера, например `http://192.168.1.20:11434/v1`, и нажмите «Проверить подключение». Для Ollama выберите точный тег модели, установленной на сервере.
4. После проверки сохраните настройки. Перед отправкой расшифровки СПИКЕР предупредит, что запрос уйдёт на другой компьютер.

Для соединения используйте только доверенную сеть. Если сервер не отвечает, проверьте адрес IPv4 через `ipconfig`, порт API, адрес прослушивания `0.0.0.0` на компьютере сервера и правило брандмауэра Windows.

СПИКЕР разрешает HTTP для частных IPv4-адресов, локальных имён компьютеров и частных IPv6-адресов. Внешние серверы должны использовать HTTPS. API-ключ по незашифрованному HTTP не передаётся.

Примечание: передача запроса подтверждается в окне СПИКЕР. Это сделано специально, потому что модель работает на другом компьютере, даже когда оба ПК находятся в вашей домашней сети.

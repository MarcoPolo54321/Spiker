# Прогресс проекта

Этот файл отражает только активную работу, не историю чатов. Завершённое удаляется; история остаётся в Git. Подробные приоритеты и планы по продукту находятся в `ARCHITECTURE_AND_ROADMAP_3.1.0.md`.

Состояние на 2026-11-18. Текущая версия в основной ветке: 3.1.5.

## Сейчас

- Внедряется стандарт изменения проекта на основе `D:/devkit-main`; документационный PR ожидает ревью и слияния.

## Дальше

- Сверить карту архитектуры и ADR с кодом при следующем изменении очереди, модели, хранилища или сборки.
- Пересмотреть старую дорожную карту 3.1.0 перед использованием как актуального плана.

## Требует внимания

- Старые документы с версиями 3.0.x/3.1.0 могут описывать уже изменённое поведение; перед переносом инструкций сверять их с текущим кодом и релизным README.
- GitHub Actions не проверяет физический микрофон и пользовательские модели; эти сценарии должны быть отмечены отдельно.

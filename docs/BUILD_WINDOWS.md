# Сборка СПИКЕР для Windows

## Результат

- `dist/Spiker/Spiker.exe` и библиотеки приложения — portable onedir-сборка.
- `dist/Spiker-Portable-<версия>.zip` — переносной архив для опытных пользователей.
- `dist/Spiker-Setup-<версия>.exe` — основной установщик Windows для большинства пользователей.
- `dist/SHA256SUMS.txt` — контрольные суммы релизных файлов.

В обычном режиме установщик включает Python-приложение, Qt/PySide6, FFmpeg, необходимые библиотеки и мультиязычную модель Whisper Small (~488 МБ). Поэтому установку и базовую транскрибацию можно выполнить без подключения к интернету после скачивания одного `Setup.exe`.

Ollama, модели Vosk и языковые модели для ИИ-обработки в базовый установщик не включены. Для полностью локальной ИИ-обработки текста их нужно предварительно установить/загрузить отдельно. Не следует путать вес распознавания речи Whisper с языковой моделью для анализа текста.

## Сборка локально

На Windows 10/11 x64 установите Python 3.11 x64. Для установщика также нужен Inno Setup 6. Из корня репозитория запустите:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build_windows.ps1 -Installer
```

Сценарий создаёт изолированное `.build-venv`, устанавливает закреплённые зависимости, запускает unittest, проверяет синтаксис, скачивает Whisper Small с закреплённой ревизии Hugging Face и проверяет SHA-256, строит приложение через PyInstaller, запускает smoke-test упакованного EXE, а затем создаёт portable ZIP и Setup.exe.

Сборке требуется интернет для получения Python-пакетов и модели, если они отсутствуют в кеше сборки. Пользователю для установки уже готового `Setup.exe` интернет не требуется.

Для developer-only сборки без модели (результат потребует отдельно выбрать файл Whisper):

```powershell
.\build_windows.ps1 -WithoutWhisperModel
```

Этот вариант не предназначен для основного публичного релиза.

## GitHub Actions

Workflow `.github/workflows/windows-release.yml` запускается вручную из Actions или автоматически при push-тега `v*`. Он публикует артефакты с `Spiker-Setup-<версия>.exe`, portable ZIP и SHA-256. При теге создаётся GitHub Release с этими файлами.

## Проверка перед публикацией

На чистой Windows 10/11 x64 проверить:

- установка и удаление приложения;
- запуск после установки без установленного Python;
- запуск и транскрибация без доступа к интернету (с моделью Whisper из установщика);
- короткие WAV, MP3 и MP4;
- микрофон и диктовка;
- пауза, остановка, продолжение и восстановление очереди после перезапуска;
- экспорт TXT, DOCX, SRT и VTT;
- локальная ИИ-обработка через Ollama после предварительной загрузки модели;
- отсутствие API-ключей и конфиденциальных расшифровок в журналах.

Smoke-test в GitHub Actions проверяет импорт модулей, ресурсы, FFmpeg и инициализацию окон, но не заменяет испытания на физическом микрофоне и длительной транскрибации.

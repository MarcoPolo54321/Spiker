# План проверки СПИКЕР 3.0.7.6 — Hotfix прозрачности обучения

1. Запустить приложение на Windows 10/11.
2. На главном экране сравнить кнопки «Настройки», «Справка» и «Обучение»: базовый полупрозрачный фон, рамка и скругление должны быть одинаковыми.
3. Навести курсор на каждую из трёх кнопок: подсветка должна совпадать.
4. Нажать и удерживать каждую кнопку: pressed-состояние должно выглядеть одинаково.
5. Убедиться, что за областью самой иконки «Обучение» не появляется отдельная синяя градиентная прямоугольная подложка.
6. Открыть «Обучение» и проверить, что кнопка продолжает открывать встроенную страницу инструкции.
7. Убедиться, что PNG `icons/training_button.png` остался исходным (RGBA, прозрачный alpha, без перерисовки изображения).

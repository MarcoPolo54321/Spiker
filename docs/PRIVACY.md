# Конфиденциальность

В локальном режиме распознавание, озвучка и работа с локальной языковой моделью выполняются на компьютере. Выбор внешнего ИИ-провайдера меняет этот режим: текст запроса передаётся выбранному сервису.

Новые результаты хранятся обычными файлами в «Документы → Spiker → results» (после использования старой защищённой истории — в подпапке `current`). Приложение не просит PIN и не открывает старые зашифрованные тестовые записи. Скопировать программу и модели можно отдельно от результатов. Перед отправкой журналов и снимков экрана проверьте, нет ли в них личных данных.

На Windows ключ для внешнего ИИ хранится через системное хранилище учётных данных, если оно доступно. Каталог `models` рядом с EXE содержит веса моделей. Дополнительные модели скачиваются отдельно, с учётом условий их поставщиков.

# Конфиденциальность

СПИКЕР предназначен для локальной обработки. В локальном режиме распознавания и ИИ аудио/текст обрабатываются на компьютере пользователя, если выбранный движок также работает локально.

## Что хранится локально

В каталоге приложения находятся настройки, очередь, результаты, журналы, кэши и загруженные пользователем модели. Не загружайте эти каталоги в GitHub и не прикладывайте журналы к публичным issues без проверки.

## Внешний API

При выборе API текст транскрибации отправляется выбранному внешнему провайдеру. До передачи нужно проверить содержимое и убедиться, что отправка разрешена. API-ключ не должен записываться в `settings.json`, журнал или репозиторий; в релизной сборке он должен храниться через системное хранилище учётных данных при доступности.

## Модели

Веса Whisper, Vosk и Ollama не включаются в Git и в базовый установщик. Пользователь загружает модель отдельно и должен учитывать лицензию/условия её распространения.

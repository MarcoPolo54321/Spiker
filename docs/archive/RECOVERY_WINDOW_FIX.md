# Восстановление окна СПИКЕР после запуска через другое Python/Qt-окружение

## Что было исправлено

- `Launch_Spiker.bat` сначала использует уже существующее `.venv311`; второй каталог `.venv` создаётся только если `.venv311` отсутствует.
- Перед запуском очищаются внешние переменные `QT_PLUGIN_PATH`, `QT_QPA_PLATFORM_PLUGIN_PATH` и переменные масштабирования Qt. Они могли остаться от стороннего Qt/IDE/Conda-окружения и влиять на вид окна.
- Главное окно теперь центрируется и подбирает размер по доступной области экрана, включая экраны Windows с увеличенным DPI.
- Добавлена запись выбранного интерпретатора Python в `logs/launcher.log`.

## Как применить исправление

1. Закройте СПИКЕР.
2. Распакуйте патч поверх папки проекта, разрешив замену только перечисленных файлов.
3. Не удаляйте `.venv311`, `.venv`, `models`, `data`, `results` или `logs`.
4. Запустите `Launch_Spiker.bat`. Отдельно активировать `.venv` в PowerShell не требуется.
5. Если окно всё ещё отображается неправильно, приложите `logs/launcher.log`, `logs/errors.log` и `logs/application.log`.

Обычная команда `Activate.ps1` сама по себе не должна менять оформление GUI. Но запуск приложения из другого окружения Python/Qt может выбрать иные версии PySide6/Qt или посторонние Qt-плагины. Поэтому для диагностики используйте исправленный `Launch_Spiker.bat`.

## Проверка

В текущей среде успешно выполняются unit-тесты и проверка синтаксиса. Полноценный запуск GUI необходимо повторно проверить на Windows, где возникла проблема.

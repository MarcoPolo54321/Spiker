# План проверки СПИКЕР 3.0.7.5

## 1. Обучение и визуальная тема
1. Запустить приложение и открыть «Обучение».
2. Убедиться, что вся страница обучения не создаёт отдельную непрозрачную синюю подложку поверх главного фона.
3. Проверить каждую вкладку: внутри не должно быть серого/графитового прямоугольника `QTextBrowser`; текст находится на полупрозрачной синей панели в общей теме приложения.
4. Проверить прокрутку длинных вкладок и выделение/копирование текста.
5. Переключаться между вкладками обучения, справкой и настройками: не должно быть серых/чёрных вспышек или артефактов.

## 2. Локальная сборка Windows
1. На Windows 10/11 x64 установить Python 3.11 x64 и Python Launcher.
2. Распаковать исходный ZIP в папку с правом записи.
3. Дважды щёлкнуть `Build_Spiker_Windows_Installer.bat`.
4. Проверить, что выбран именно Python 3.11 x64, даже если другая версия Python установлена первой в PATH.
5. Проверить создание `.build-venv`, прохождение unittest и compileall, загрузку Whisper Small и T-one с проверкой весов, сборку PyInstaller и smoke-test.
6. Проверить, что Inno Setup 6 был обнаружен или установлен через WinGet.
7. Убедиться, что в `dist` появились `Spiker-Setup-3.0.7.5.exe`, `Spiker-Portable-3.0.7.5.zip` и `SHA256SUMS.txt`.
8. Установить Setup на отдельную тестовую учётную запись Windows, запустить СПИКЕР без установленного Python и проверить Whisper.cpp и T-one.
9. Удалить приложение штатным деинсталлятором.

## 3. Ограничения комплекта
- Vosk, faster-whisper/CTranslate2, pyannote и Ollama не включены в Setup по умолчанию; они устанавливаются отдельно.
- Для pyannote пользователь принимает условия модели и предоставляет Hugging Face Read-токен.
- Сборка требует интернета для Python-пакетов, модели Whisper и T-one.

## 4. Отчёт о проверке
Записать версию Windows, Python, результат каждого этапа сборки, размеры установщика/portable ZIP, а также ошибки из консоли и папки `logs`.
